# MoSS website

Static website for **MoSS — Molecular Solid Solutions**, ready for GitHub Pages.

## Pages

- `index.html` — home
- `mossinfo.html` — about the programme
- `team.html` — team
- `publications.html` — publications
- `blog.html` — MoSS blog
- `news.html` — programme news
- `challenge.html` — Challenge MoSS / industry engagement
- `outreach.html` — outreach and engagement
- `partners.html` — partners
- `resources.html` — community resources
- `contact.html` — contact information

Shared styling is in `styles.css` and mobile navigation is in `script.js`.
Images are stored in `assets/images/`.

The home page uses `assets/images/moss-pill.webp`, a web-optimised version of the MoSS pill artwork.

## Publish on GitHub Pages

1. Create or open the GitHub repository for the website.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will show the public site URL once deployment completes.

## Editing

All pages are plain HTML and can be edited directly in GitHub or in a code editor.
The navigation and footer are duplicated on each page so the site requires no build system.
